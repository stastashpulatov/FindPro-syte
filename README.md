# FindPro - Платформа поиска специалистов

Полноценное веб-приложение для поиска и найма профессиональных специалистов. Клиенты могут создавать заявки на услуги, а специалисты отправлять свои предложения.

## ✨ Возможности

- 🏠 **Главная страница** - красивый лендинг с категориями услуг
- 📝 **Создание заявок** - простая форма для описания задачи
- 💼 **Управление заявками** - просмотр, редактирование и удаление
- 💰 **Система предложений** - специалисты могут отправлять свои цены
- ✅ **Принятие/отклонение** - выбор лучшего предложения
- 👥 **Каталог специалистов** - поиск проверенных профессионалов
- 🔐 **Аутентификация** - безопасный вход через JWT

## 🛠 Технологии

### Frontend
- **React 18** - современная библиотека для UI
- **Tailwind CSS** - utility-first CSS framework
- **Lucide React** - красивые иконки
- **Axios** - HTTP клиент для API запросов

### Backend
- **FastAPI** - современный Python веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **Pydantic** - валидация данных
- **JWT** - токены для аутентификации
- **SQLite/PostgreSQL** - база данных

## 🚀 Быстрый старт

### ⚡ Автоматическая установка (Рекомендуется)

Самый быстрый способ запустить проект:

```bash
# Сделайте скрипт исполняемым
chmod +x setup.sh

# Запустите установку
./setup.sh
```

Скрипт автоматически:
- Проверит зависимости
- Создаст виртуальное окружение
- Установит все пакеты (backend + frontend)
- Настроит базу данных и создаст тестовых пользователей
- Подготовит конфигурационные файлы

### Ручная установка Frontend

```bash
# Установите зависимости
npm install

# Запустите сервер разработки
npm start
```

Фронтенд будет доступен на `http://localhost:3000`

### Ручная установка Backend

```bash
# Перейдите в директорию backend
cd backend

# Создайте виртуальное окружение
python3 -m venv .venv

# Активируйте его
source .venv/bin/activate  # Linux/Mac
# или .venv\Scripts\activate для Windows

# Установите зависимости
pip install -r requirements.txt

# Инициализируйте базу данных
python init_db.py
python seed_categories.py
python create_test_user.py

# Запустите сервер
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен на:
- API: `http://localhost:8000`
- Документация: `http://localhost:8000/docs`

## 🔄 Совмещённый запуск

В корне проекта доступны скрипты для одновременного запуска backend и frontend.

### Разработка

```bash
./scripts/run-dev.sh
```

Параметры можно переопределить переменными среды:

```bash
PYTHON_BIN=python3.11 BACKEND_PORT=8001 FRONTEND_PORT=3001 ./scripts/run-dev.sh
```

Скрипт:
- создаёт и активирует виртуальное окружение `backend/.venv`;
- устанавливает Python-зависимости и инициализирует БД;
- автоматически освобождает занятые порты `BACKEND_PORT`/`FRONTEND_PORT` (по умолчанию 8000/3000), завершая процессы, которые их используют;
- запускает FastAPI (`uvicorn --reload`);
- после готовности backend поднимает React Dev Server с `REACT_APP_API_URL`, указывающим на работающий backend.

Порты можно переопределить:

```bash
BACKEND_PORT=8100 FRONTEND_PORT=3100 ./scripts/run-dev.sh
```

### Продакшн / staging

```bash
HOST_DOMAIN=coolbola.uz \
HOST_DATA_ROOT=/var/lib/findpro \
UVICORN_WORKERS=4 \
./scripts/run-prod.sh
```

Скрипт:
- создаёт/использует виртуальное окружение и ставит зависимости;
- гарантирует, что база данных хранится в `DATABASE_PATH` (по умолчанию `HOST_DATA_ROOT/findpro.db`). Если переменная `DATABASE_URL` не задана, автоматически устанавливается `sqlite:////<путь>` и передаётся всем backend-процессам;
- автоматически освобождает занятые порты перед запуском backend/frontend;
- собирает frontend с `REACT_APP_API_URL`. Если указан `HOST_DOMAIN`, то по умолчанию используется `https://<HOST_DOMAIN>/api/v1`;
- запускает `uvicorn` (в прод-режиме, без `--reload`) и `npx serve -s build -l <порт>`.  
  Для реального продакшена рекомендуется повесить на этот порт nginx/PM2 или изменить `FRONTEND_PORT=80`/`FRONTEND_HOST=127.0.0.1`.

Полезные переменные для хостинга `coolbola.uz`:

| Переменная | Назначение | Значение по умолчанию |
|-----------|------------|-----------------------|
| `HOST_DOMAIN` | Домен, который будет использоваться в ссылках (например, `coolbola.uz`) | пусто |
| `HOST_DATA_ROOT` | Папка, где хранится база данных и другие данные | `<repo>/data` |
| `DATABASE_PATH` | Путь к SQLite-файлу | `<HOST_DATA_ROOT>/findpro.db` |
| `DATABASE_URL` | Полностью переопределяет подключение к БД (например, PostgreSQL) | генерируется из `DATABASE_PATH` |
| `BACKEND_HOST` | IP, на котором слушает uvicorn | `0.0.0.0` |
| `FRONTEND_HOST`/`FRONTEND_PORT` | Адрес/порт статического сервера | `0.0.0.0:4173` (или `:80`, если указан `HOST_DOMAIN`) |

> Если скрипт запущен под обычным пользователем и вы пытаетесь занять порт 80/443, используйте `sudo` или настройте обратный прокси (nginx) на эти порты, а `serve`/`uvicorn` оставьте на внутренних (например, 8000 и 4173).

## 🎯 Основные функции

1. Создание заявки на услугу
2. Просмотр предложений от специалистов
3. Принятие/отклонение предложений
4. Управление своими заявками

1. Просмотр доступных заявок
2. Отправка предложений с ценой
3. Управление своим профилем
4. Получение уведомлений о новых заявках

## 🐛 Отладка

Если возникают проблемы:

1. **Проблемы с CORS**: Убедитесь, что backend запущен на порту 8000
2. **Ошибки авторизации**: Проверьте, что токен сохраняется в localStorage
3. **Ошибки БД**: Запустите `python init_db.py` заново
